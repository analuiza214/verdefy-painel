# Estado da matriz limpa

Modelo genérico para nova configuração. Não possui domínio real, administrador, credenciais, banco ou conexão ativa. Exemplos usam nomes e IDs fictícios.

Cada usuário deve ter painel individual, conexões próprias e dados isolados. O código existente usa administrador e conexão gerais por instalação: a maneira compatível hoje é criar instalação exclusiva por usuário. Seguir ASSISTENTE-CONFIGURACAO-E-USUARIOS.md para criar cada instalação independente.
